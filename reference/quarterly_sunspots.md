# Quarterly mean relative sunspots number from 1749-1983

Quarterly mean relative sunspots number from 1749-1983

## Usage

``` r
quarterly_sunspots
```

## Format

A data frame with 940 rows and 4 variables

- year:

- qu:

  quarter

- spots:

  total number of sunspots

- mean_spots_per_year:

## Source

Andrews, D. F. and Herzberg, A. M. (1985) Data: A Collection of Problems
from Many Fields for the Student and Research Worker. New York:
Springer-Verlag.
